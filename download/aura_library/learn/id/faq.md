## Aura dasar

Pertanyaan inti tentang cara kerja Aura, model yang didukung, dan cara Anda memulai.
### Bagaimana cara kerja Aura?

Aura adalah asisten desain AI berbasis web. Anda dapat menghasilkan desain HTML, CSS, dan JavaScript menggunakan teks prompt, mereferensikan template dan komponen dengan @, mengedit secara visual di Mode Desain, dan menerbitkan atau mengekspor karya Anda. Semua pemrosesan terjadi di browser dan cloud.
### Bisakah saya menghasilkan desain dengan Aura?

Ya. Aura termasuk generasi desain sehingga Anda dapat membuat konten visual menggunakan teks prompt. Pro dan Max membuka kunci mode desain dan opsi ekspor.
### Apakah Aura bekerja secara offline?

Tidak. Aura adalah aplikasi web yang memerlukan koneksi internet untuk mengakses model AI dan menghasilkan konten. Semua pemrosesan terjadi di cloud untuk performa terbaik dan akses model terbaru.
### Model AI apa yang didukung Aura?

Aura mengintegrasikan Grok 4.3, GPT-5.5, GPT-5.4, Claude Opus 4.7, Claude Sonnet 4.6, dan Gemini 3.1 Pro. Pro dan Max membuka kunci model Claude premium untuk hasil berkualitas lebih tinggi.
### Aplikasi apa yang dapat diintegrasikan dengan Aura?

Aura dapat mengekspor desain ke Figma menggunakan metode konsol browser, dan Anda dapat mengimpor desain dari Figma dengan menempelkan URL Figma. Anda juga dapat mengekspor situs lengkap sebagai file HTML/CSS/JS untuk melanjutkan pengembangan di editor kode apa pun atau deploy ke platform hosting seperti Netlify atau Vercel.
### Apa persyaratan sistem untuk Aura?

Aura adalah aplikasi web yang berfungsi di browser modern apa pun. Anda memerlukan koneksi internet yang stabil dan browser web modern seperti Chrome, Firefox, Safari, atau Edge. Tidak ada unduhan atau instalasi yang diperlukan—cukup kunjungi aura.build dan mulai membuat.
### Bisakah mencoba Aura sebelum membeli?

Ya. Mulai trial 3 hari Pro, Max, atau Ultra dengan 20 trial prompt. Metode pembayaran diperlukan, dan Anda tidak akan dikenai biaya jika membatalkan sebelum trial berakhir.
## Harga & pembayaran

Detail paket, batasan, dan kontrol billing diambil dari Konten Harga dan FAQ inti.
### Paket harga apa yang ditawarkan Aura?

Aura dimulai dengan trial 3 hari Pro, Max, atau Ultra yang mencakup 20 trial prompt. Paket berbayar kemudian meningkatkan batasan pesan bulanan: Pro memiliki 120, Max memiliki 240, Ultra memiliki 560, dan Elite memiliki 1,080.
### Bagaimana cara kerja batasan pesan?

Semua model AI (Grok, GPT, Claude, Gemini) dihitung terhadap batasan penggunaan yang sama. Pro, Max, dan Ultra trial mencakup 20 trial prompt, Pro mendapatkan 120 pesan bulanan setelah trial, Max mendapatkan 240, Ultra mendapatkan 560, dan Elite mendapatkan 1,080.
### Bagaimana cara kerja trial?

Pro, Max, dan Ultra dimulai dengan trial 3 hari dan 20 trial prompt. Metode pembayaran diperlukan untuk memulai; batalkan sebelum trial berakhir untuk menghindari dikenai biaya.
### Bisaya meningkatkan atau menurunkan paket saya?

Ya. Peningkatan berlaku secara langsung; penurunan berlaku pada siklus pembayaran berikutnya.
### Apakah pesan yang tidak digunakan dibawa ke bulan berikutnya?

Tidak. Batasan pesan diatur ulang setiap siklus pembayaran untuk semua paket.
### Metode pembayaran apa yang Anda terima?

Kartu kredit utama dan Apple Pay melalui Stripe didukung untuk langganan.
## Fitur & alur kerja

Semua tentang template, editor, dan bagaimana Aura berbeda dari alat lain.
### Cara menggunakan @ untuk mereferensikan template dan komponen?

Gunakan @ dalam prompt untuk menarik template, komponen, atau snippet—hingga ~100.000 karakter konteks. Shift-klik untuk mereferensikan beberapa item sekaligus.
### Bisakah saya membuat situs web multi-halaman dengan Aura?

Ya. Buat sebanyak halaman yang Anda butuhkan, tautkan elemen untuk navigasi, tambahkan transisi halaman, dan pertahankan komponen yang konsisten di seluruh situs.
### Cara menggunakan template ini?

Template Gratis atau Pro dapat di-remix dengan tombol "Gunakan Gratis" atau "Gunakan sebagai Pro". Template berbayar memerlukan menggunakan tautan "Beli" penulis untuk mendapatkan akses.
### Bisakah saya menyesuaikan template ini?

Ya. Setelah di-remix atau membeli, Anda dapat mengubah warna, font, gambar, layout, dan konten, atau mengedit kode secara langsung dengan prompt.
### Apakah saya memerlukan Pro untuk menggunakan template ini?

Template premium memerlukan langganan Pro. Template berbayar memerlukan pembelian dari penulis terlepas dari paket Anda.
### Bisakah saya meng-remix atau berbagi versi saya?

Ya. Anda dapat meng-remix template untuk membuat versi Anda sendiri dan berbagi remix Anda dengan komunitas; kredit tetap milik Anda.
### Mengapa elemen menghilang di Tampilan Desain/Kode?

Animasi berat dapat menyembunyikan elemen. Hapus atau sederhanakannya, atau gunakan snippet Animate Keyframe/Animate on Scroll yang telah dioptimalkan untuk editor.
### Apa perbedaannya dengan Lovable?

Aura berfokus pada output desain berbasis Tailwind: HTML/CSS/JS nyata, 1.700+ template, 1.400+ komponen, situs multi-halaman, dan editing visual. Lovable lebih berorientasi pada aplikasi full-stack.
### Apa perbedaannya dengan Framer, Webflow, atau Figma Sites?

Aura menghasilkan HTML standar, Tailwind CSS, dan vanilla JS—tanpa runtime propieter. Anda dapat mengekspor, self-host, atau terus mengedit di editor kode atau Figma apa pun.
### Apakah saya terikat dengan Aura saat mendesain dan menerbitkan?

Tidak, itu hanya HTML dan Anda dapat mengonversinya ke Figma menggunakan alat kami, Framer menggunakan plugin mereka dan platform populer lain yang menggunakan HTML.
### Bisakah Anda mengimpor font yang tidak ada di dalam Aura?

Ya, Anda hanya perlu menyebutkan nama font dalam prompt. Atau Anda dapat melakukannya di kode. Selama itu font online seperti Google Fonts, atau URL, itu akan berfungsi.
### Proyek saya membutuhkan sumber daya yang intensif dan layar membeku saat saya mencoba membuat perubahan. Apa yang harus saya lakukan?

Jika halaman Anda membeku saat mencoba membuat perubahan, pergi ke Home dan klik "Iterations" di sebelah Chat. Arahkan kursor ke iterasi dan klik Delete. Sebelum menghapus, salin kode Anda sebagai cadangan untuk menghindari kehilangan data. Untuk mengoptimalkan proyek Anda tanpa mengedit kode, buat beberapa halaman—setiap halaman baru menggandakan aslinya, yang kemudian dapat Anda sesuaikan dengan meminta AI untuk menghapus bagian tertentu atau kode yang tidak digunakan. Anda juga dapat meminta AI untuk menghapus atau menyesuaikan animasi untuk performa yang lebih baik. Pendekatan ini membantu mengurangi ukuran file dan mencegah pembekuan tanpa memerlukan pengeditan kode langsung.
### Mengapa Aura tidak ingat pilihan halaman saya sebelumnya saat saya beralih ke halaman baru?

Saat ini, Aura hanya memproses halaman yang sedang Anda lihat secara aktif di editor dan tidak mempertahankan konten dari halaman sebelumnya atau mempertahankan riwayat build lengkap. Ini disengaja untuk menjaga performa optimal dan menghindari membebani sistem dengan terlalu banyak konten. Namun, saat bekerja di satu halaman, Aura akan membaca hingga beberapa ribu baris HTML halaman tersebut untuk membantu Anda. Jika Anda perlu mereferensikan bagian yang telah selesai, yang terbaik adalah menyalin detail yang diperlukan ke konten halaman saat ini atau memberikan ringkasan prompt saat Anda bekerja. Kami sedang bekerja untuk meningkatkan penanganan konten di pembaruan mendatang, dan umpan balik Anda membantu memprioritaskan peningkatan ini.
### Cara mendesain setiap halaman secara terpisah di Aura dan menggabungkannya?

Anda dapat memprompt dan mendesain setiap halaman secara terpisah di Aura. Untuk menghubungkan halaman, gunakan fitur "Link"—klik kanan elemen dan pilih "Copy", lalu pergi ke halaman target dan gunakan "Paste to Replace" jika diperlukan. Ini membantu mentransfer bagian atau elemen navigasi di antara halaman. Jika alur kerja ini tidak memenuhi kebutuhan Anda, Anda dapat mengunduh file HTML dari Aura dan mengimpor ke Cursor. Dari sana, Anda dapat meminta Cursor untuk membangun atau menyempurnakan struktur sebagai proyek lengkap.
### Saya mencoba menambahkan logo kustom ke landing page yang saya bangun tetapi saya tidak tahu cara mengunggah aset saya sendiri.

Saat ini, pengunggahan SVG langsung belum didukung. Namun, Anda dapat menyalin kode SVG dari file Anda dan menyertakannya langsung di prompt bahkan beberapa SVG sekaligus. Alternatifnya, Anda dapat mengunggah file SVG Anda ke platform hosting eksternal ( atau server FTP) dan mereferensikan URL publik di prompt Anda.
## SEO & penerbitan

Cara menambahkan metadata pencarian sebelum menerbitkan dan menyesuaikannya untuk setiap halaman.
### Cara menambahkan SEO ke situs Aura saya?

Buka popover Publish, beralih ke tab SEO, pilih Home atau halaman tertentu, lalu isi judul, kata kunci, deskripsi, favicon, dan override spesifik halaman sebelum menerbitkan.
### Apakah saya perlu mengedit header situs secara manual?

Tidak. Untuk metadata SEO normal, gunakan tab Publish SEO. Aura menyimpan bidang SEO dengan proyek yang diterbitkan sehingga bertahan saat republishing, perubahan halaman, dan pembaruan domain.
### Bisakah menyesuaikan SEO untuk setiap halaman?

Ya. Gunakan dropdown Page di dalam tab SEO. Home berfungsi sebagai default situs, dan halaman individual dapat memiliki judul, kata kunci, deskripsi, dan gambar pratinjau sosial sendiri.
### Apa yang harus saya tulis di judul SEO?

Tulis janji yang jelas untuk halaman tertentu, lalu tambahkan merek saat membantu pengenalan. Hindari judul generik seperti Home, Landing Page, atau Page 1.
### Apa yang harus diperiksa setelah menerbitkan?

Periksa halaman publik, robots.txt, sitemap.xml, dan llms.txt jika tersedia. Kemudian verifikasi domain di Google Search Console, kirimkan sitemap, dan periksa URL paling penting.
### Apakah domain kustom membantu SEO?

Domain kustom bukan strategi peringkat itu sendiri, tetapi memberi situs rumah kanonik yang mudah diingat. Pilih satu host utama dan gunakan secara konsisten di tautan, Search Console, dan sitemap.
## Penerbitan & ekspor

Cara menerbitkan, mengekspor, menghosting, dan menghubungkan formulir atau domain untuk proyek Anda.
### Bisakah mengekspor template ini?

Ya. Setelah di-remix dan disesuaikan, Anda dapat mengekspor sebagai HTML atau kirim ke Figma. Opsi ekspor tersedia di editor.
### Bisakah mengekspor desain situs saya dari Aura?

Ya. Ekspor situs lengkap sebagai HTML/CSS/JS, terbitkan ke subdomain, atau ekspor ke Figma. Semua output adalah kode standar yang dapat Anda lanjutkan di mana saja.
### Cara menambahkan domain saya sendiri?

Ekspor situs Anda, deploy ke Netlify atau Vercel, lalu konfigurasikan domain kustom dan DNS di dashboard mereka.
### Cara membangun beberapa halaman?

Buat halaman di popover Pages, tautkan elemen ke halaman, dan kelola navigasi. Menduplikasi halaman tidak membuat halaman baru secara otomatis—Anda menambahkannya secara eksplisit.
### Di mana harus menghosting landing page saya?

Ekspor HTML dan drag-and-drop ke Netlify atau Vercel. Keduanya memiliki hosting cepat, setup rendah dengan paket gratis.
### Kemana pengiriman formulir pergi?

Formulir kosong secara default. Hubungkan tindakan ke Netlify Forms, Formspree, Getform, atau Google Forms (beberapa baris JS) untuk menyimpan pengiriman.
### Apa yang terjadi pada animasi Unicorn Studio jika server down?

Aset animasi Unicorn Studio dihosting di Unicorn Studio secara default. Jika Anda lebih suka menghosting aset sendiri untuk kontrol atau keandalan lebih, Anda dapat mengikuti panduan resmi mereka: [https://www.unicorn.studio/docs/faqs/](https://www.unicorn.studio/docs/faqs/)
