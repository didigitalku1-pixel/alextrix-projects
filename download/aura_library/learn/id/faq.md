## Aura dasar

Pertanyaan inti tentang cara Aura bekerja, model apa yang didukung, dan bagaimana Anda bisa memulai.
### Bagaimana cara Aura bekerja?

Aura adalah asisten desain AI berbasis web. Anda dapat menghasilkan desain HTML, CSS, dan JavaScript menggunakan text prompt, mereferensikan template dan komponen dengan @, secara visual di Mode Desain, dan menerbitkan atau mengekspor kreasi Anda. Semua pemrosesan terjadi di browser Anda dan di cloud.
### Bisakah saya menghasilkan desain dengan Aura?

Ya. Aura mencakup generasi desain sehingga Anda dapat membuat konten visual menggunakan text prompt. Paket Pro dan Max membuka kunci mode desain dan opsi ekspor.
### Apakah Aura bekerja secara offline?

Tidak. Aura adalah aplikasi berbasis web yang memerlukan koneksi internet untuk mengakses model AI dan menghasilkan konten. Semua pemrosesan terjadi di cloud untuk performa terbaik dan akses model terbaru.
### Model AI apa yang didukung oleh Aura?

Aura mengintegrasikan Grok 4.3, GPT-5.5, GPT-5.4, Claude Opus 4.7, Claude Sonnet 4.6, dan Gemini 3.1 Pro. Paket Pro dan Max membuka kunci model Claude premium untuk hasil berkualitas lebih tinggi.
### Aplikasi apa yang dapat diintegrasikan dengan Aura?

Aura dapat mengekspor desain ke Figma menggunakan metode browser console, dan Anda dapat mengimpor desain dari Figma dengan menempelkan URL Figma. Anda juga dapat mengekspor situs lengkap sebagai file HTML/CSS/JS untuk melanjutkan pengembangan di editor kode apa pun atau mendeploy ke platform hosting seperti Netlify atau Vercel.
### Apa persyaratan sistem untuk Aura?

Aura adalah aplikasi web yang berfungsi di browser modern apa pun. Anda memerlukan koneksi internet stabil dan browser web modern seperti Chrome, Firefox, Safari, atau Edge. Tidak diperlukan unduhan atau instalasi—cukup kunjungi aura.build dan mulai membuat.
### Bisakah saya mencoba Aura sebelum membeli?

Ya. Mulai trial Pro, Max, atau Ultra selama 3 hari dengan 20 trial prompt. Metode pembayaran diperlukan, dan Anda tidak akan dikenakan biaya jika Anda membatalkan sebelum trial berakhir.
## Harga & pembayaran

Detail paket, batasan, dan kontrol pembayaran yang diambil dari Halaman Harga dan konten FAQ inti.
### Paket harga apa yang ditawarkan Aura?

Aura dimulai dengan trial Pro, Max, atau Ultra selama 3 hari yang mencakup 20 trial prompt. Paket berbayar kemudian meningkatkan batas pesan bulanan: Pro memiliki 120, Max memiliki 240, Ultra memiliki 560, dan Elite memiliki 1.080.
### Bagaimana cara kerja batas pesan?

Semua model AI (Grok, GPT, Claude, Gemini) dihitung terhadap batas penggunaan yang sama. Trial Pro, Max, dan Ultra mencakup 20 trial prompt, Pro mendapatkan 120 pesan bulanan setelah trial, Max mendapatkan 240, Ultra mendapatkan 560, dan Elite mendapatkan 1.080.
### Bagaimana cara kerja trial?

Pro, Max, dan Ultra dimulai dengan trial selama 3 hari dan 20 trial prompt. Metode pembayaran diperlukan untuk memulai; batalkan sebelum trial berakhir untuk menghindari dikenakan biaya.
### Bisakah saya meningkatkan atau menurunkan paket saya?

Ya. Peningkatan berlaku secara segera; penurunan berlaku pada siklus tagihan berikutnya.
### Apakah pesan yang tidak digunakan dibawa ke bulan berikutnya?

Tidak. Jatah pesan diatur ulang setiap siklus tagihan untuk semua paket.
### Metode pembayaran apa yang Anda terima?

Kartu kredit utama dan Apple Pay melalui Stripe didukung untuk berlangganan.
## Fitur & alur kerja

Semua tentang template, editor, dan bagaimana Aura berbeda dari alat lain.
### Bagaimana cara menggunakan @ untuk mereferensikan template dan komponen?

Gunakan @ di prompt untuk menarik template, komponen, atau snippet—hingga ~100.000 karakter konteks. Shift-klik untuk mereferensikan beberapa item sekaligus.
### Bisakah saya membuat situs web multi-halaman dengan Aura?

Ya. Buat sebanyak halaman yang Anda butuhkan, hubungkan elemen untuk navigasi, tambahkan transisi halaman, dan pertahankan komponen yang konsisten di seluruh situs.
### Bagaimana cara menggunakan template ini?

Template Gratis atau Pro dapat di-remix dengan tombol "Gunakan Gratis" atau "Gunakan sebagai Pro". Template berbayar memerlukan menggunakan tautan "Beli" penulis untuk mendapatkan akses.
### Bisakah saya menyesuaikan template ini?

Ya. Setelah di-remix atau membeli, Anda dapat mengubah warna, font, gambar, tata letak, dan konten, atau mengedit kode secara langsung dengan prompt.
### Apakah saya memerlukan Pro untuk menggunakan template ini?

Template premium memerlukan langganan Pro. Template berbayar memerlukan pembelian dari penulis terlepas dari paket Anda.
### Bisakah saya meng-remix atau berbagi versi saya?

Ya. Anda dapat meng-remix template untuk membuat versi Anda sendiri dan berbagi remix Anda dengan komunitas; kredit tetap milik Anda.
### Mengapa elemen menghilang di Tampilan Desain/Kode?

Animasi berat dapat menyembunyikan elemen. Hapus atau sederhanakan mereka, atau gunakan snippet Animate Keyframe/Animate on Scroll yang telah dioptimalkan untuk editor.
### Apa perbedaannya dengan Lovable?

Aura berfokus pada output desain berbasis Tailwind: HTML/CSS/JS nyata, 1.700+ template, 1.400+ komponen, situs multi-halaman, dan editing visual. Lovable lebih berorientasi pada aplikasi full-stack.
### Apa perbedaannya dengan Framer, Webflow, atau Figma Sites?

Aura menghasilkan HTML standar, Tailwind CSS, dan vanilla JS—tanpa runtime propieter. Anda dapat mengekspor, self-host, atau terus mengedit di editor kode atau Figma apa pun.
### Apakah saya terikat pada Aura saat mendesain dan menerbitkan?

Tidak, itu hanya HTML dan Anda dapat mengonversinya ke Figma menggunakan alat kami, Framer menggunakan plugin mereka dan platform populer lainnya yang menggunakan HTML.
### Bisakah Anda mengimpor font yang tidak ada di dalam Aura?

Ya, Anda hanya perlu menyebutkan nama font di prompt. Atau Anda dapat melakukannya di kode. Selama itu adalah font online seperti Google Fonts, atau URL, itu akan berfungsi.
### Proyek saya memerlukan sumber daya yang intensif dan layar membeku saat saya mencoba membuat perubahan. Apa yang harus saya lakukan?

Jika halaman Anda membeku saat mencoba membuat perubahan, pergi ke Home dan klik pada "Iterasi" di sebelah Chat. Arahkan kursor ke iterasi dan klik Hapus. Sebelum menghapus, salin kode Anda sebagai cadangan untuk menghindari kehilangan data. Untuk mengoptimalkan proyek Anda tanpa mengedit kode, buat beberapa halaman—setiap halaman baru menggandakan aslinya, yang kemudian dapat Anda sesuaikan dengan meminta AI untuk menghapus bagian tertentu atau kode yang tidak digunakan. Anda juga dapat meminta AI untuk menghapus atau menyesuaikan animasi untuk performa yang lebih baik. Pendekatan ini membantu mengurangi ukuran file dan mencegah pembekuan tanpa memerlukan pengeditan kode langsung.
### Mengapa Aura tidak mengingat pilihan halaman sebelumnya saya saat saya beralih ke halaman baru?

Saat ini, Aura hanya memproses halaman yang sedang Anda lihat secara aktif di editor dan tidak mempertahankan konten dari halaman sebelumnya atau mempertahankan riwayat build lengkap. Ini disengaja untuk menjaga performa optimal dan menghindari membebani sistem dengan terlalu banyak konteks. Namun, saat bekerja pada satu halaman, Aura akan membaca hingga beberapa ribu baris HTML dari halaman tersebut untuk membantu Anda. Jika Anda perlu merujuk bagian yang telah selesai sebelumnya, yang terbaik adalah menyalin detail yang diperlukan ke konteks halaman saat ini atau memberikan ringkasan prompt saat Anda bekerja. Kami sedang bekerja untuk meningkatkan penanganan konten dalam pembaruan di masa depan, dan umpan balik Anda membantu memprioritaskan peningkatan ini.
### Bagaimana cara mendesain setiap halaman secara terpisah di Aura dan menggabungkannya?

Anda dapat memprompt dan mendesain setiap halaman secara terpisah di Aura. Untuk menghubungkan halaman, gunakan fitur "Link"—klik kanan elemen dan pilih "Salin", kemudian pergi ke halaman target dan gunakan "Tempel untuk Mengganti" sesuai kebutuhan. Ini membantu mentransfer bagian atau elemen navigasi di antara halaman. Jika alur kerja ini tidak memenuhi kebutuhan Anda, Anda dapat mengunduh file HTML dari Aura dan mengimpor ke Cursor. Dari sana, Anda dapat memprompt Cursor untuk membangun atau menyempurnakan struktur sebagai proyek lengkap.
### Saya mencoba menambahkan logo kustom ke landing page yang saya bangun tetapi saya tidak tahu cara mengunggah aset saya sendiri.

Saat ini, unggahan SVG langsung belum didukung. Namun, Anda dapat menyalin kode SVG dari file Anda dan menyertakannya langsung di prompt bahkan beberapa SVG sekaligus. Alternatifnya, Anda dapat mengunggah file SVG Anda ke platform hosting eksternal (atau server FTP) dan mereferensikan URL publik di prompt Anda.
## SEO & penerbitan

Cara menambahkan metadata pencarian sebelum menerbitkan dan menyesuaikannya untuk setiap halaman.
### Bagaimana cara menambahkan SEO ke situs Aura saya?

Buka popover Publish, beralih ke tab SEO, pilih Beranda atau halaman tertentu, lalu isi judul, kata kunci, deskripsi, favicon, dan override spesifik halaman sebelum menerbitkan.
### Apakah saya perlu mengedit header situs secara manual?

Tidak. Untuk metadata SEO normal, gunakan tab Publish SEO. Aura menyimpan bidang SEO dengan proyek yang diterbitkan sehingga mereka bertahan saat republishing, perubahan halaman, dan pembaruan domain.
### Bisakah saya menyesuaikan SEO untuk setiap halaman?

Ya. Gunakan dropdown Halaman di dalam tab SEO. Beranda berfungsi sebagai default situs, dan halaman individual dapat memiliki judul, kata kunci, deskripsi, dan gambar pratinjau sosial sendiri.
### Apa yang harus saya tulis di judul SEO?

Tulis janji yang jelas untuk halaman tertentu, lalu tambahkan merek ketika membantu pengenalan. Hindari judul generik seperti Beranda, Landing Page, atau Halaman 1.
### Apa yang harus saya periksa setelah menerbitkan?

Periksa halaman publik, robots.txt, sitemap.xml, dan llms.txt jika tersedia. Kemudian verifikasi domain di Google Search Console, kirim sitemap, dan periksa URL yang paling penting.
### Apakah domain kustom membantu SEO?

Domain kustom bukan strategi peringkat itu sendiri, tetapi memberi situs rumah kanonik yang mudah diingat. Pilih satu host utama dan gunakan secara konsisten di tautan, Search Console, dan sitemap.
## Penerbitan & ekspor

Cara menerbitkan, mengekspor, meng-hosting, dan menghubungkan formulir atau domain untuk proyek Anda.
### Bisakah saya mengekspor template ini?

Ya. Setelah di-remix dan disesuaikan, Anda dapat mengekspor sebagai HTML atau kirim ke Figma. Opsi ekspor tersedia di editor.
### Bisakah saya mengekspor desain situs saya dari Aura?

Ya. Ekspor situs lengkap sebagai HTML/CSS/JS, terbitkan ke subdomain, atau ekspor ke Figma. Semua output adalah kode standar yang dapat Anda lanjutkan di mana saja.
### Bagaimana cara menambahkan domain saya sendiri?

Ekspor situs Anda, deploy ke Netlify atau Vercel, lalu konfigurasikan domain kustom dan DNS di dashboard mereka.
### Bagaimana cara membangun halaman ganda?

Buat halaman di popover Pages, hubungkan elemen ke halaman, dan kelola navigasi. Menyalin halaman tidak membuat otomatis yang baru—Anda menambahkannya secara eksplisit.
### Di mana saya harus meng-hosting landing page saya?

Ekspor HTML dan drag-and-drop ke Netlify atau Vercel. Keduanya memiliki hosting cepat, pengaturan rendah dengan rencana gratis.
### Kemana pengiriman formulir pergi?

Formulir kosong secara default. Hubungkan tindakan ke Netlify Forms, Formspree, Getform, atau Google Forms (beberapa baris JS) untuk menyimpan pengiriman.
### Apa yang terjadi dengan animasi Unicorn Studio jika server down?

Aset animasi Unicorn Studio dihosting secara default di Unicorn Studio. Jika Anda lebih suka meng-host aset sendiri untuk kontrol atau keandalan lebih, Anda dapat mengikuti panduan resmi mereka: [https://www.unicorn.studio/docs/faqs/](https://www.unicorn.studio/docs/faqs/)
